# Checklist for automodel

Copy to the project root; tick as you go (status details live in `CONTEXT.md`).

## Phase 1 — Setup
- [ ] Size classified; goal, data, decision rule (read back on a reference), external evidence, budget agreed
- [ ] `RUN_PLAN.md` approved (light: whole plan; heavy: part A); `CONTEXT.md` created

## Phase 2 — Baseline
- [ ] Baseline, shared harness (records, card, validator, budget counter) and evaluator tests
- [ ] End-to-end pilot on the real execution path; references scored; calibration recorded
- [ ] Heavy: `RUN_PLAN.md` part B approved

## Phase 3 — Iterate (per meta-iteration)
- [ ] Status checkpointed and progress reported before launch; agents launched within the budget
- [ ] Review: invalid attempts quarantined, shortlist refitted, recombination, re-orientation, usage, re-plan, `meta_m/review.md`; status checkpointed
- [ ] Progress message sent; paused if the plan says so
- [ ] At the end: authorised consolidation, finalists and trade-offs reported; owned jobs and processes stopped

## Phase 4 — Finalize
- [ ] Applicable validation, freeze, pre-registration and clean-checkout checks completed, or omissions recorded
- [ ] Final checks done within the authorised allowance, or omitted with the reason recorded (or the winner re-verified and labelled exploratory)
- [ ] Outcome (eligible winner, or none) with metrics, claims and limitations recorded
